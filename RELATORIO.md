## 1. Passo a Passo do Desenvolvimento
1. **Escolha do Tema:** Definição do tema "Guia de Counter-Strike 2" para explorar layout responsivo dark/gaming.
2. **Desenvolvimento Web:**
   - Criação da estrutura semântica em HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
   - Estilização com CSS3 puro (Flexbox, CSS Grid, variáveis CSS, gradientes e responsividade).
3. **Controle de Versão (Git & GitHub):**
   - Inicialização do repositório local e estruturação dos commits organizados por etapa.
   - Vinculação com o repositório remoto público no GitHub.
4. **Hospedagem no GitHub Pages:**
   - Ativação da publicação via branch principal (`main`/`root`).

---

## 2. Ferramentas Utilizadas
- **Git & GitHub:** Versionamento de código e hospedagem pública.
- **GitHub Pages:** Publicação da página estática de forma gratuita e acessível via link público.
- **HTML5 & CSS3:** Utilizados de forma nativa, garantindo que o projeto não utilize frameworks ou JavaScript.

---

## 3. Conceitos Aprendidos
- Publicação e hospedagem de sites estáticos utilizando o GitHub Pages.
- Versionamento de código através do Git (`init`, `add`, `commit`, `push`).
- Formatação de documentação utilizando a linguagem de marcação Markdown (`.md`).
- Organização e responsividade CSS sem o uso de bibliotecas externas.
